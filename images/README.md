# Images Directory

This directory is reserved for diagrams, figures, and visual documentation for the Runtime-Adaptive FPGA Video LUT Reconfiguration project.

## Intended Diagram Assets

Future image files may include:

- System block diagram
- LUT reconfiguration flow diagram
- Shadow-buffer activation diagram
- Active/shadow LUT bank diagram
- AXI4-Lite register map diagram
- Diagnostic readback path diagram
- Live video pipeline integration diagram
- Verification and validation flow diagram

## Suggested File Structure

```text
images/
  system-block-diagram.png
  lut-reconfiguration-flow.png
  shadow-buffer-activation.png
  active-shadow-bank-switching.png
  register-map-overview.png
  diagnostic-readback-path.png
  live-video-pipeline-integration.png
  validation-flow.png
```

## Diagram Style Guidance

Recommended diagram style:

- 16:9 aspect ratio for presentation reuse
- Clean engineering block-diagram layout
- Clear signal-flow arrows
- Separate control path and video path
- Consistent naming with repository documentation
- Export in PNG and optionally SVG format
